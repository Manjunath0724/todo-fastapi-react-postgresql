How to manually run the TaskFlow Pro project:

You will need to open two separate terminal (PowerShell or Command Prompt) windows: one for the backend, and one for the frontend.

=====================================================
TERMINAL 1: Backend Setup & Execution
=====================================================
1. Open your first terminal and navigate to the project directory:
   cd "C:\Users\asus\Desktop\Final TTL Projecet"

2. Navigate to the backend folder:
   cd backend

3. Create a Python virtual environment (you only need to do this once):
   python -m venv venv

4. Activate the virtual environment:
   # On PowerShell:
   .\venv\Scripts\Activate.ps1
   # Or on Command Prompt:
   .\venv\Scripts\activate.bat

5. Install the required backend dependencies:
   pip install -r requirements.txt

6. Start the backend server:
   uvicorn main:app --reload

The backend is now running at: http://localhost:8000
API Docs are available at: http://localhost:8000/docs


=====================================================
TERMINAL 2: Frontend Setup & Execution
=====================================================
1. Open a second, new terminal window and navigate to the project directory:
   cd "C:\Users\asus\Desktop\Final TTL Projecet"

2. Navigate to the frontend folder:
   cd frontend

3. Install the required frontend dependencies (using legacy peer deps to avoid conflicts):
   npm install --legacy-peer-deps

4. Start the React development server:
   npm start

The frontend is now running at: http://localhost:3000

=====================================================

Note: Don't forget to configure the backend/.env file with your database URL and SMTP credentials for full application functionality.
